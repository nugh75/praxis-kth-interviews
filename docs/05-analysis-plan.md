# Analysis Plan

## Analytic approach

The analysis is qualitative and codebook-guided. PRAXIS provides the deductive frame, while interview material may generate KTH-specific subcodes through documented inductive refinement.

## Workflow

1. Prepare de-identified transcript.
2. Segment transcript into meaningful units.
3. Apply PRAXIS codes.
4. Add candidate KTH subcodes only when needed.
5. Write an interview memo.
6. Compare within group: faculty, doctoral students, students.
7. Compare across groups.
8. Build traceability table for every claim used in writing.

## Coding phases

### Phase 1: Pilot coding

Code 2 interviews from different participant groups.

Goals:

- test interview protocol;
- check whether original PRAXIS codes are sufficient;
- identify confusing probes;
- refine codebook candidates.

### Phase 2: Main coding

Code all de-identified interviews.

Use multi-coding when a segment expresses both practice and evaluation, for example a concrete tool use plus concern about privacy.

### Phase 3: Cross-case synthesis

Build matrices by:

- participant group;
- PRAXIS dimension;
- KTH-specific subcode;
- type of practice;
- type of concern;
- institutional support gap.

## Claims

Every claim must be grounded in at least one de-identified excerpt. Comparative claims must be grounded across enough cases to avoid anecdotal overstatement.

Avoid:

- "KTH thinks..."
- "students believe..."
- "faculty are..."

Prefer:

- "In the interviews coded so far, several doctoral students described..."
- "Among the faculty interviews, a recurrent pattern was..."
- "This appears in one interview only and should be treated as a case-specific account."
